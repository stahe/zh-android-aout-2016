# 使用 Android Studio 进行 Android 平板电脑编程入门（2016）

👉 **相关课程：**
[使用 Android Studio 进行 Android 平板电脑编程入门（2016）](https://stahe.github.io/zh-android-aout-2016/)

---

## 📖 概述

本文是对多篇 Android 开发教学资源的改写与整合。旨在为 Android 应用程序编程（特别是平板电脑应用）提供**循序渐进且结构化的入门指南**。

本文包含以下重要更新：

* 采用 **Android Studio** 作为主要开发环境
* 使用 **Gradle** 构建系统
* 引入 **RxJava** 用于处理异步操作
* Android 应用的高级架构（片段、生命周期、客户端/服务器架构）

本文件的一个核心特点是介绍了 **适用于 Android 客户端/服务器应用的通用框架**，该框架可在众多项目中重复使用。





---

## 🎯 学习目标

* 掌握 Android 开发的基础知识
* 熟练掌握视图与片段之间的导航
