    4. TP 1：工资单的基本管理

    4.1. Introduction

    为了应用之前所学的内容，我们现在提出一项任务：编写一个适用于平板电脑的 Android 客户端，用于模拟某协会员工工资单的计算。

    该应用将采用客户端/服务器架构：

    • 服务器 [1] 已提供；
    • 需自行构建 Android 客户端 [2]。

    4.2. 数据库

    4.2.1. 定义

    用于生成工资单的静态数据将存储在一个数据库中，我们将其命名为 dbpam。该数据库包含以下表：

    表 EMPLOYES：汇总了关于各保育员的信息

    结构：

    ID
    主键
    VERSION
    版本号——每修改一行即递增
    SS
    员工社保号——唯一编号
    NOM
    员工姓名
    PRENOM
    其名字
    ADRESSE
    他的地址
    VILLE
    他的城市
    CODEPOSTAL
    他的邮政编码
    INDEMNITE_ID
    表[INDEMNITES]中字段[ID]的外键

    其内容可能如下：

    表 COTISATIONS：汇总计算社会保险费所需的百分比

    结构：

    ID
    主键
    VERSION
    版本号——每修改一行即递增
    CSGRDS
    百分比：普遍社会缴费 + 社会债务偿还缴费
    CSGD
    百分比：可抵扣的通用社会保险费
    SECU
    百分比：社会保险、丧偶保险、养老保险
    RETRAITE
    百分比：补充养老金 + 失业保险

    其内容可能如下：

    社会保险费率与员工无关。上表仅有一行。

    表 INDEMNITES：汇总了用于计算应付工资的各项要素。
    ID
    主键
    VERSION
    版本号——每修改一行即递增
    INDICE
    处理索引 - 唯一
    BASEHEURE
    每小时看护服务的净价（欧元）
    ENTRETIENJOUR
    每小时看护的欧元生活津贴
    REPASJOUR
    每日看护的餐费补贴（欧元）
    INDEMNITESCP
    带薪休假补贴。该金额为基本工资的百分比。

    其内容可能如下：

    需注意，不同保育员的津贴可能有所不同。这些津贴实际上是通过保育员的薪级指数与特定保育员关联的。 例如，薪级指数为2的Marie Jouveinal女士（表EMPLOYES），其时薪为2.1欧元（表INDEMNITES）。

package client.android.dao.service;

import java.util.List;

public class Response<T> {

    // 操作状态

    public Response() {

    }

    public Response(int status, List<String> messages, T body) {
        this.status = status;
        this.messages = messages;
        this.body = body;
    }

...
}

    4.4. Android 客户端测试

    以下是已完成的Android客户端可执行二进制文件：

      

    请使用鼠标将上方的二进制文件 [pam-client.apk] 拖放到平板模拟器 [GenyMotion] 上。该文件将被保存并执行。如果尚未启动，请同时启动 Web 服务器 / jSON。 Android客户端的目的是获取Web服务器 / jSON 返回的信息并进行格式化。Android客户端的各个视图如下：

    首先需连接至 Web 服务 / jSON：

    • 在 [1] 中，需提供 Web 服务 / jSON 的 URL。 使用模拟器时，请输入 PC 的其中一个地址 IP（但不要输入 127.0.0.1）。 使用平板电脑时，请输入Web服务器主机的Wi-Fi地址 / jSON，并禁用服务器端的防火墙（如有），以免其阻挡传入请求；

    随后将进入模拟页面：

    • 在 [3] 中，选择一名员工；
    • 在 [4] 页面，输入工时数；

    • 在 [6] 中，执行模拟；
